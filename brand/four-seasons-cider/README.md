# Four Seasons Cider Co.: brand kit

Classic Apple Cider, a Central Otago cider. It is a collaboration between Earnscleugh Juice Co. and Double Cone Brewing.

- **Product:** pure juice, medium sweet, zero fuss. 4.5%, 330 ml, 1.2 standard drinks.
- **Tagline:** Pick. Press. Sip.
- **Planned handle:** @fourseasonscider. The accounts don't exist yet.
- **Approval:** Steve has a business partner, so every post needs Steve's approval before it goes out.
